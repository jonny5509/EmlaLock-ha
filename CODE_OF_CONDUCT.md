# Code of Conduct

## Our standards

We want these projects to be welcoming, respectful, and constructive spaces for everyone.

Expected behavior includes:

- Being respectful and considerate of others.
- Giving constructive feedback focused on the work, not the person.
- Assuming good faith and asking questions before making assumptions.
- Respecting different backgrounds, experiences, and perspectives.
- Keeping discussions relevant to the project.

Unacceptable behavior includes:

- Harassment, discrimination, or personal attacks.
- Threats, intimidation, or deliberately disruptive behavior.
- Trolling, insulting, or deliberately inflammatory comments.
- Publishing private or sensitive information without permission.
- Other conduct that would reasonably make the community unsafe or unwelcome.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or take other reasonable action when behavior violates this Code of Conduct.

If you experience or witness unacceptable behavior, report it privately to the project maintainers through the contact method listed in the repository profile. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of using public issues.

Reports will be handled as confidentially as practical.

## Scope

This Code of Conduct applies to project spaces, including issues, pull requests, discussions, and other community interactions associated with these repositories.
