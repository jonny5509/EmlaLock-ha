# Security Policy

## Supported versions

Security fixes are provided for the current release line.

| Version | Supported |
| --- | --- |
| 1.3.x | Yes |
| < 1.3 | No |

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

For a private report, use GitHub's **Report a vulnerability** feature on this repository's Security tab. Include:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The affected version(s).
- The potential impact.
- Any proof-of-concept or relevant logs, with secrets and personal information removed.

If GitHub's private vulnerability reporting is unavailable, contact the repository maintainers through the contact method listed in the repository profile.

## Response

Maintainers will review valid security reports and, where appropriate, work with the reporter on a fix and coordinated disclosure.

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.
